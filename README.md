# LinkTracker

**LinkTracker** – распределенный Telegram-бот, который отслеживает изменения на веб-страницах и оперативно информирует пользователя о них. 

## Что реализовано (Чек-лист требований)

**Функциональные требования:**
- [x] Обработка команды `/start` (начало диалога, регистрация чата).
- [x] Обработка команды `/help` (вывод списка доступных команд).
- [x] Обработка команды `/track` (добавление ссылки с использованием диалоговых состояний).
- [x] Обработка команды `/untrack` (удаление ссылки из мониторинга).
- [x] Обработка команды `/list` (просмотр отслеживаемых ссылок).
- [x] Обработка неизвестных команд и команды `/cancel`.

**Архитектурные и системные требования:**
- [x] **Различные протоколы связи:** Клиенты и серверы для интеграции между сервисами поддерживают HTTP (REST) или gRPC в зависимости от конфигурации (`transport_mode`).
- [x] **Структурное логирование (`log/slog`).**
- [x] **Защищенная конфигурация через `config.json`.**
- [x] **PostgreSQL-хранилище:** миграции SQL, запуск миграций из кода, переключение `access_type` (`SQL`/`ORM`).

**Автотесты:**
- [x] Unit-тесты для команд и роутера.
- [x] Свежие интеграционные тесты (папка `tests/integration`).

## Установка и настройка

1. Склонируйте репозиторий и перейдите в корневую папку проекта.
2. Установите зависимости:
   ```bash
   make tidy
   ```
3. **Настройка конфигурации:**
   - Скопируйте файл-шаблон:
     ```bash
     cp config.example.json config.json
     ```
   - Заполните `config.json` актуальными данными, включая токен от BotFather в поле `telegram_token`.
  - При необходимости выберите `transport_mode` (`http` или `grpc`).
  - Для `scrapper` настройте доступ к БД:
    - `access_type`: `SQL` или `ORM`
    - `db_dsn`: строка подключения к PostgreSQL
    - `auto_migrate`: применять ли SQL-миграции при старте.

## Запуск проекта

В проекте настроен `Makefile` для удобной работы. Все команды выполняются из корня проекта.

**Для локальной разработки:**
- Поднять PostgreSQL: `make db-up`
- Бот: `make run-bot`
- Парсер: `make run-scrapper`
- Агент: `make run-agent`
- Отчеты: `make run-report`

**Сборка бинарных файлов:**
```bash
make build
# Будут собраны все сервисы в папке ./bin/
./bin/bot
./bin/scrapper
```

## Запуск тестов

Тесты покрывают бизнес-логику команд и HTTP/gRPC обертку.
- Для запуска модульных тестов:
  ```bash
  make test
  ```
- Для запуска интеграционных тестов:
  ```bash
  make integration
  ```

### Примечания по БД

- SQL-миграции находятся в каталоге `migrations/`.
- Локальный Postgres поднимается из `docker-compose.yml`.
- Интеграционные тесты БД используют Testcontainers (чистая БД + программный запуск миграций).

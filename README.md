# LinkTracker

**LinkTracker** – Telegram-бот, который отслеживает изменения на веб-страницах и оперативно информирует пользователя о них.

## Что реализовано (Чек-лист требований)

**Функциональные требования:**
- [x] Обработка команды `/start` (приветственное сообщение).
- [x] Обработка команды `/help` (вывод списка доступных команд).
- [x] Обработка неизвестных команд (сообщение об ошибке).

**Нефункциональные требования:**
- [x] **Типобезопасная конфигурация:** Настройки читаются из `config.json` в строгую Go-структуру. Токен не захардкожен и скрыт через `.gitignore`.
- [x] **Структурное логирование:** Использован стандартный пакет `log/slog`. Логи выводятся в формате JSON с добавлением полезных `key-value` параметров (`chat_id`, `command`, `username`, `error`).
- [x] **Автотесты:** Реализовано unit-тестирование (blackbox) роутера команд с использованием Table-Driven Tests и мокирования (Dependency Injection через интерфейс `Sender`). Не отправляет реальные запросы в Telegram при тестах.

**Бонусные требования:**
- [x] **Автоматическая настройка меню команд:** При старте бот вызывает метод `setMyCommands` и автоматически отображает команды `/start` и `/help` в интерфейсе Telegram (кнопка "Menu").

## Установка и настройка

1. Склонируйте репозиторий и перейдите в корневую папку проекта.
2. Установите зависимости:
   ```bash
   make tidy
   # или: go mod tidy
   ```
3. **Настройка конфигурации:**
   - Скопируйте файл-шаблон конфигурации:
     ```bash
     cp config.example.json config.json
     ```
   - Откройте `config.json` и вставьте ваш токен от BotFather в поле `telegram_token`.

---

## Запуск проекта

В проекте настроен `Makefile` для удобной работы. Все команды выполняются из корня проекта.

**Для локальной разработки (запуск на лету):**
```bash
make run
```
*(Если Make не установлен, используйте: `go run ./cmd/bot/main.go`)*

**Для сборки бинарного файла:**
```bash
make build
./bin/bot
```

---

## Запуск тестов

Тесты покрывают позитивные сценарии (`/start`, `/help`) и негативные сценарии (неизвестная команда).
Для запуска тестов с подробным выводом выполните:

```bash
make test
```
*(Или: `go test ./... -v`)*
